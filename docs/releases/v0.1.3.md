# Connect My World in Herdr v0.1.3

Herdr 연결을 확인하고 재연결하는 macOS 메뉴바 앱의 첫 공개 릴리즈입니다.

- 서버 상태 확인과 개별/전체 재연결
- Proxmox 아래에 VM 묶기와 `└` 표시
- 실패 상태, 인증 취소 경합, 부분 실패와 오래된 등록 정보 처리
- 선택 가능한 Mac 로그인 시 자동 실행

## 다운로드

`connect-my-world-in-herdr-v0.1.3-macos-arm64.zip`을 압축 해제한 뒤 앱을 Applications에 옮겨 실행하세요. `SHA256SUMS.txt`로 파일 해시를 확인할 수 있습니다.

**Apple Silicon(M1 이상), macOS 15 이상**이 필요합니다. `/opt/homebrew/bin/herdr`와 기존 Herdr/SSH 등록 설정을 사용하며 MADP에는 `/opt/homebrew/bin/tsh`가 필요합니다.

Apple 개발자 서명·공증 없이 배포하며 로컬 ad-hoc 서명만 포함합니다. 첫 실행이 차단되면 시스템 설정 → 개인정보 보호 및 보안 → 확인 없이 열기(Open Anyway)를 이용하세요. [Apple 실행 안내](https://support.apple.com/en-us/102445)

## 알려진 제한

- MADP 로그인 링크는 비어 있습니다. 실제 브라우저→tsh 연결은 보류 상태입니다.
- 상태는 원격 서버 응답 기준이며 Herdr UI의 최종 연결 상태와 다를 수 있습니다.
- 자동 시작, 실제 브라우저 인증과 GUI 버튼 전체 흐름은 미검증입니다.
- Intel Mac과 사용자 지정 도구 경로는 이번 배포 파일에서 지원하지 않습니다.

로컬 Swift Testing 14개와 릴리즈 빌드로 검증했습니다. 서버 설정·SSH 키·인증 토큰은 포함하지 않았습니다.
