# Connect My World in Herdr v0.2.0

MADP의 Teleport(tsh) 경로를 제거한 릴리즈입니다. 이제 MADP를 포함한 모든 서버를 기존 OpenSSH 설정으로 직접 확인하고 재연결합니다.

## 변경 사항

- Teleport/tsh 인증 확인, "인증 필요" 상태, MADP 로그인 링크 설정과 인증 대기 흐름 제거
- `/opt/homebrew/bin/tsh`가 더 이상 필요하지 않음
- 설정 화면에는 로그인 시 자동 실행 항목만 남음

## 업그레이드 시 확인

- MADP는 Herdr에 일반 SSH 대상(예: Tailscale 주소)으로 등록해 사용하세요. 이전 `madp`(Teleport) 등록이 남아 있으면 다른 서버와 똑같이 SSH로 확인합니다.
- 꺼진 연결도 "전체 재연결"이나 행 클릭으로 다시 켜집니다. 쓰지 않는 등록은 Herdr에서 지워주세요.

## 다운로드

`connect-my-world-in-herdr-v0.2.0-macos-arm64.zip`을 압축 해제한 뒤 앱을 Applications에 옮겨 실행하세요. `SHA256SUMS.txt`로 파일 해시를 확인할 수 있습니다.

**Apple Silicon(M1 이상), macOS 15 이상**이 필요합니다. `/opt/homebrew/bin/herdr`와 기존 Herdr/SSH 등록 설정을 사용합니다.

Apple 개발자 서명·공증 없이 배포하며 로컬 ad-hoc 서명만 포함합니다. 첫 실행이 차단되면 시스템 설정 → 개인정보 보호 및 보안 → 확인 없이 열기(Open Anyway)를 이용하세요. [Apple 실행 안내](https://support.apple.com/en-us/102445)

## 알려진 제한

- 상태는 원격 서버 응답 기준이며 Herdr UI의 최종 연결 상태와 다를 수 있습니다.
- 자동 시작과 GUI 버튼 전체 흐름은 미검증입니다.
- Intel Mac과 사용자 지정 도구 경로는 이번 배포 파일에서 지원하지 않습니다.

로컬 Swift Testing 9개와 릴리즈 빌드로 검증했습니다. 서버 설정·SSH 키·인증 토큰은 포함하지 않았습니다.
